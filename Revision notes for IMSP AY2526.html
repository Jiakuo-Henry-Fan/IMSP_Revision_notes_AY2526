Revision Note – LaTeX & Python Templates

LaTeX

Presettings & Frontpages

  1. Document setup

    
\documentclass{article}
\title{Title}
\author{Author}
\date{\today}
\begin{document}
    \maketitle
    \tableofcontents
    \listoffigures
    \listoftables
    \newpage
    % content
\end{document}

  2. Sections

    
\section{Section}
\subsection{Subsection}
\subsubsection{Subsubsection}

Lists

  • Unordered 
    
\begin{itemize}
    \item Item 1
    \item Item 2
\end{itemize}
  • Ordered 
    
\begin{enumerate}
    \item Item 1
    \item Item 2
\end{enumerate}

Math

  • Inline: $E=mc^2$
  • Display: \[E=mc^2\]
  • Numbered equation: 
    
\begin{equation}
    E=mc^2
\end{equation}
    (use equation* to hide number)
  • Align: 
    
\begin{align}
    a &= b + c \\
    d &= e + f
\end{align}
  • Matrix (bracket): 
    
\begin{bmatrix}
    a & b \\
    c & d
\end{bmatrix}
  • Matrix (parenthesis): 
    
\begin{pmatrix}
    a & b \\
    c & d
\end{pmatrix}

Tables and Figures

  • Figure 
    
\begin{figure}
    \centering
    \includegraphics{image.png}   % file in same folder
    \caption{Caption}
    \label{fig:my-fig}
\end{figure}
  • Table (floating) 
    
\begin{table}
    \centering
    \begin{tabular}{|c|c|c|}
        \hline
        Col1 & Col2 & Col3 \\
        \hline
        A    & B    & C    \\
        \hline
    \end{tabular}
    \caption{Caption}
    \label{tab:my-tab}
\end{table}

2. Matplotlib – Plot templates


import matplotlib.pyplot as plt

Line plot with customisation


x = np.linspace(0, 2*np.pi, 200)
plt.plot(x, np.sin(x), 'r--', linewidth=2, label='sin')
plt.plot(x, np.cos(x), 'b-', label='cos')
plt.xlabel('x'), plt.ylabel('y')
plt.title('Trig functions')
plt.legend(), plt.grid(True)
plt.show()

Scatter plot + regression line


# generate noisy data
x = np.random.rand(50) * 10
y = 2 * x + 3 + np.random.randn(50)

# fit polynomial of degree 1
fit = Polynomial.fit(x, y, 1)
coeff = fit.convert()

plt.scatter(x, y, alpha=0.6, label='data')
x_line = np.linspace(x.min(), x.max(), 100)
plt.plot(x_line, fit(x_line), 'red', label=f'y = {coeff[0]:.2f} + {coeff[1]:.2f}x')
plt.legend()
plt.show()
